# Max Travel booking platform

Next.js customer website with a PostgreSQL-backed account and booking foundation. Live supplier/payment operations are not yet connected.

See [DELIVERY-STATUS.md](DELIVERY-STATUS.md) for setup, verification results and release blockers.

Run `npm run dev -- --hostname 127.0.0.1`. Development database and Mailpit setup is in `compose.dev.yaml`. Keep all real credentials out of source control.
